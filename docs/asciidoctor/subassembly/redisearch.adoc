[[redisearch]]
==== redisearch

封装同步模板 `RedisSearchTemplate`、`StringRedisSearchTemplate`，以及响应式模板 `ReactiveRedisSearchTemplate`、`StringReactiveRedisSearchTemplate`。 +
自动配置基于 lettuce-mod 创建 `LettuceModConnectionFactory`（实现 `RedisSearchConnectionFactory`）。存在 Jackson 时，对象模板使用 JSON 编解码；classpath 上有 Reactor 时注册响应式模板。

===== 配置

配置前缀为 `spring.redisearch`，默认连接 `localhost:6379` 的 `0` 号库。

[source,yaml,indent=0]
----
spring:
  redisearch:
    host: localhost
    port: 6379
    database: 0
    username:
    password:
    ssl: false
    timeout: 3s
    client-name: redisearch-client
    pool:
      enabled: true
      max-active: 8
      max-idle: 8
      min-idle: 0
      max-wait: -1ms
----

集群模式可启用 `cluster` 配置：

[source,yaml,indent=0]
----
spring:
  redisearch:
    cluster:
      enabled: true
      nodes:
        - 127.0.0.1:6379
        - 127.0.0.1:6380
      max-redirects: 3
----

===== 使用模板

`RedisSearchTemplate<String, Object>` 适合对象读写，`StringRedisSearchTemplate` 适合字符串场景。 +
同步调用使用 `executeSync`，异步调用使用 `executeAsync`。`executeAsync` 在回调返回 `CompletionStage` 时会持有连接直到完成。

响应式场景注入 `ReactiveRedisSearchTemplate` 或 `StringReactiveRedisSearchTemplate`。 +
`execute` 返回 `Mono`，`executeMany` 返回 `Flux`。连接在订阅时借出，发布者结束时归还；未订阅不会占用连接。

如果需要调整 lettuce 的底层资源，可以注册 `ClientResourcesBuilderCustomizer`。

[source,java,indent=0]
----
@Service
public class ArticleSearchService {

	private final StringRedisSearchTemplate stringRedisSearchTemplate;

	public ArticleSearchService(StringRedisSearchTemplate stringRedisSearchTemplate) {
		this.stringRedisSearchTemplate = stringRedisSearchTemplate;
	}

}
----

[source,java,indent=0]
----
@Service
public class ReactiveArticleSearchService {

	private final StringReactiveRedisSearchTemplate stringReactiveRedisSearchTemplate;

	public ReactiveArticleSearchService(StringReactiveRedisSearchTemplate stringReactiveRedisSearchTemplate) {
		this.stringReactiveRedisSearchTemplate = stringReactiveRedisSearchTemplate;
	}

	public Flux<String> ping() {
		return stringReactiveRedisSearchTemplate.executeMany(commands -> commands.ping().flux());
	}

}
----
