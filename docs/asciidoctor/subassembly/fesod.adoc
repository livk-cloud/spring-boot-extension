[[fesod]]
==== fesod

Fesod 组件封装 FastExcel 的导入导出能力，并接入 Spring MVC / WebFlux 方法参数解析和返回值处理。

===== Excel导入

在上传方法上声明 `@RequestExcel`，用 `@ExcelParam` 绑定解析后的数据。支持 Spring MVC 与 WebFlux。 +
`@ExcelParam.fileName` 指定 multipart 文件名，默认是 `file`。解析由内置的 `TypeExcelMapReadListener` 完成，按参数类型读取行数据。

[source,java,indent=0]
----
@RestController
public class InfoController {

	@RequestExcel
	@PostMapping("uploadList")
	public HttpEntity<List<Info>> uploadList(@ExcelParam List<Info> dataExcels) {
		return ResponseEntity.ok(dataExcels);
	}

	@RequestExcel
	@PostMapping("upload")
	public HttpEntity<List<Info>> upload(@ExcelParam(fileName = "file") List<Info> dataExcels) {
		return ResponseEntity.ok(dataExcels);
	}

	@RequestExcel
	@PostMapping("uploadMono")
	public Mono<HttpEntity<List<Info>>> uploadMono(@ExcelParam Mono<List<Info>> dataExcels) {
		return dataExcels.map(ResponseEntity::ok);
	}

}
----

`@RequestExcel` 声明当前方法接收 Excel 上传，`@ExcelParam` 绑定解析后的数据。`fileName` 必须写成注解属性，不能写成 `@ExcelParam("file")`。 +
WebFlux 可以使用 `Mono<List<T>>` 接收解析结果。

===== Excel导出

`@ResponseExcel` 标记在方法上，`@ExcelController` 标记在类上，把返回值写成 Excel 下载。支持 Spring MVC 与 WebFlux。 +
`fileName` 指定下载文件名，`suffix` 指定后缀，默认 `XLSM`。`@ExcelController` 的默认文件名是 `out`，后缀同样是 `xlsm`。

返回 `List<?>`、`Mono<List<?>>` 或 `Flux<?>` 时，sheet 名称是 `sheet`。 +
返回 `Map<String, ?>` 或 `Mono<Map<String, ?>>` 时，map key 作为 sheet 名称。

[source,java,indent=0]
----
@RestController
public class InfoController {

	@ResponseExcel(fileName = "outFile")
	@RequestExcel
	@PostMapping("uploadDownLoad")
	public List<Info> uploadDownLoad(@ExcelParam List<Info> dataExcels) {
		return dataExcels;
	}

	@ResponseExcel(fileName = "outFile")
	@RequestExcel
	@PostMapping("uploadDownLoadMono")
	public Mono<List<Info>> uploadDownLoadMono(@ExcelParam Mono<List<Info>> dataExcels) {
		return dataExcels;
	}

	@ResponseExcel(fileName = "outFile")
	@RequestExcel
	@PostMapping("uploadDownLoadFlux")
	public Flux<Info> uploadDownLoadFlux(@ExcelParam Mono<List<Info>> dataExcels) {
		return dataExcels.flatMapMany(Flux::fromIterable);
	}

}
----

[source,java,indent=0]
----
@ExcelController
public class Info2Controller {

    @PostMapping("download")
    public Map<String, List<Info>> download(@RequestBody List<Info> dataExcels) {
        return dataExcels.stream()
                .collect(Collectors.groupingBy(info -> String.valueOf(Long.parseLong(info.getPhone()) % 10)));
    }
}
----

`@ResponseExcel` 可以标记在方法上；`@ExcelController` 可以标记在类上，对类内返回结果统一进行 Excel 输出处理。 +
返回 `Map<String, ?>` 时，map key 会作为 sheet 名称。

===== 文件名和后缀

`@ResponseExcel` 支持指定 `fileName` 和 `suffix`。如果使用 `@ExcelController` 默认配置，文件名为 `out`，后缀为 `xlsm`。

===== fesod-spring-boot-starter

artifactId: fesod-spring-boot-starter

根据Servlet环境自动注册 *ExcelMethodArgumentResolver* 和 *ExcelMethodReturnValueHandler* +

或Reactive环境自动注册 *ReactiveExcelMethodReturnValueHandler* 和 *ReactiveExcelMethodArgumentResolver*

===== 注意事项

导入按参数类型读取行数据，大文件仍会进入内存，上传体积需要在网关或容器层限制。 +
导出多 sheet 时返回 `Map<String, List<?>>`，map key 会作为 sheet 名称。
