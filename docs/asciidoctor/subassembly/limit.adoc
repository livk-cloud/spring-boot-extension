[[limit]]
==== limit

限流组件通过 `@Limit` 标记方法，并由 `LimitInterceptor` 拦截执行。 +
默认提供 `RedissonLimitExecutor`，适合多实例部署下共享限流状态。

===== Limit注解

标记方法,用于对此方法进行限流

使用示例

[source,java,indent=0]
----
public class UserService {

  @Limit(key = "livk:user", rate = 2, rateInterval = 30)
  public void save(User user) {

  }
}
----

`@Limit` 常用属性：

* `key`：限流资源 key，建议按业务域命名。
* `rate`：单位时间内允许的令牌数。
* `rateInterval`：单位时间长度。
* `rateIntervalUnit`：时间单位，默认 `SECONDS`。
* `restrictIp`：是否按请求 IP 追加限制维度。
* `handler`：触发限流后的自定义处理器。

===== LimitExecutor

`LimitExecutor` 是限流执行器。自定义存储时实现该接口并注册为 Spring Bean。 +
内置 `RedissonLimitExecutor`，依赖 `RedissonClient`。`limit-spring-boot-starter` 已经传递引入 `redisson-spring-boot-starter`。

===== LimitInterceptor

限流拦截器基于 AOP 拦截 `@Limit` 方法。它会在可用的 `LimitExecutor` 中选择一个执行限流。

===== limit-spring-boot-starter

artifactId: limit-spring-boot-starter

引入 starter 后，还要在配置类上声明 `@EnableLimit`，自动配置才会注册拦截器。业务方法再使用 `@Limit`。

[source,java,indent=0]
----
@EnableLimit
@SpringBootApplication
public class LimitApplication {

}
----
